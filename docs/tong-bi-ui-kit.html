Gắn ảnh nền vào

Mỗi màn hình có một biến nền riêng. Khi ảnh từ Gemini đã xuất WebP, chỉ cần trỏ đường dẫn:

.man-doan-tong .nen-page{
  background-image: url("/nen/p08_guess_9x16.webp");
}

Giữ nguyên class .an-toan — nó phủ một lớp tối tông đất ở khoảng giữa để panel giấy dó luôn đọc được, kể cả khi ảnh nền sáng hơn dự tính.

Nếu ảnh chưa có, gradient tạm trong file này đã đúng tông màu, nên có thể ghép giao diện và code gameplay song song mà không phải chờ art.
